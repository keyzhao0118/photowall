# 🌟 照片墙 PhotoWall

一个动态流动的照片墙网页应用，适合公司宣传屏幕展示。

## 功能特性

- **蜂窝状动态布局** — 照片像 Apple Watch 应用一样呈六边形蜂窝排列
- **自动随机流动** — 不操作时照片墙持续随机滚动
- **鼠标/触控拖拽控制** — 拖拽鼠标控制流动方向和速度
- **单击放大查看** — 点击任意照片进入详情模式
- **点赞系统** — 每张照片支持点赞，数据持久化存储
- **目录选取** — 支持选择任意本地文件夹作为照片来源
- **可爱字体展示** — 使用站酷快乐体显示姓名

## 使用方式

1. 用 Chrome/Edge 浏览器打开 `index.html`（本地文件）或部署到 Web 服务器
2. 页面默认展示内置演示照片
3. 点击左上角「📁 选择照片目录」按钮，选取你存放照片的文件夹
4. 照片会以蜂窝状排列并自动流动
5. 拖拽鼠标控制流动方向，点击照片查看详情并点赞

## 照片命名规则

目录中的照片文件命名即为展示的姓名（不含扩展名），例如：
- `张可爱.jpg` → 展示为「张可爱」
- `李晓明.png` → 展示为「李晓明」

## 点赞数据

点赞数据保存在所选目录的 `photowall-likes.json` 文件中，下次打开同一目录时自动同步。

## 技术栈

- 纯前端实现，无需后端
- Canvas 渲染 + requestAnimationFrame 动画
- File System Access API 实现本地目录读写
- 站酷快乐体（ZCOOL KuaiLe）可爱字体
