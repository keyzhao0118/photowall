# 🌟 照片墙 PhotoWall

> 一个会「流动」的蜂窝状照片墙，专为公司宣传屏 / 展示大屏设计。

**🔗 在线地址：<https://keyzhao0118.github.io/photowall/>**

---

## ✨ 效果说明

- **每张照片都是一个独立个体** — 它们由六边形锚点"拴着"，但牵引绳有 24px 松弛量，所以每张都在自己的一小片水域里自由游走，绝不是钉在格点上
- **水面漂浮感** — 内置平滑时空流场（多重正弦叠加），每张照片采样自己所在位置的流速，像水下暗流推着它们走；同时每张还有独立的自转摇摆与呼吸缩放
- **彼此排开** — 照片之间互相排斥，靠太近会自然分开，整体布局持续呼吸重组
- **点击水面激起波纹** — 单击空白水面，扩散的同心圆环会把扫过的照片径向冲开，画面瞬间"炸"开再慢慢归位
- **拖拽搅动水流** — 按住拖动就像用手推一整片水，所有照片顺着方向漂移，鼠标周围还会荡起小涟漪尾迹
- **光标拨水** — 鼠标移到哪，照片就像被手指拨开的水一样向两边散开
- **绝不重叠** — 采用 PBD 位置约束求解，数学上保证任意两张照片永不重叠
- **永不空屏** — 边界引力算法会让照片簇漂移过远时被平滑拉回，屏幕中心永远有照片
- **可爱字体展示姓名** — 圆形照片底部叠加暗色渐变，用「站酷快乐体」显示姓名（离线自动回退到「幼圆」）
- **单击放大 + 点赞** — 点击任意照片弹出大图，带点赞按钮、实时点赞数和飘心动画
- **点赞数据落盘** — 点赞数写入照片目录内的 `photowall-likes.json`，下次打开同一目录自动同步
- **目录可随时更换** — 顶栏「📁 选择照片目录」按钮

## 🚀 使用方式

### 1. 打开页面

用 **Chrome** 或 **Edge** 打开：<https://keyzhao0118.github.io/photowall/>

> ⚠️ 必须用 Chrome / Edge（需要 File System Access API）。
> ⚠️ 必须通过 `https://` 或 `http://localhost` 访问，直接双击本地 `index.html`（`file://`）**无法**读取目录。

首次打开会显示内置的 30 张演示照片，直接就能看到完整动态效果。

### 2. 选择你的照片目录

点击顶栏 **📁 选择照片目录** → 选中存放照片的文件夹 → 允许「查看和修改文件」权限。

### 3. 照片命名规则

**文件名（去掉扩展名）就是展示的姓名**：

| 文件名 | 墙上显示 |
|--------|---------|
| `张可爱.jpg` | 张可爱 |
| `李晓明.png` | 李晓明 |
| `王小花.webp` | 王小花 |

支持的格式：`.jpg` `.jpeg` `.png` `.gif` `.webp` `.bmp` `.avif`

### 4. 点赞

单击任意照片 → 弹出大图 → 点「❤️ 点赞」。
点赞数会立即写入所选目录中的 `photowall-likes.json`：

```json
{
  "张可爱": 15,
  "吴糖果": 42,
  "陈星星": 23
}
```

下次打开页面并选择同一目录时，点赞数会自动读回来。

## 🖥️ 宣传屏部署建议

### 目录权限记住机制

页面会把目录句柄存进浏览器的 IndexedDB。下次打开时：

- 若权限仍有效 → **自动加载**，无需任何操作
- 若浏览器要求重新确认 → 顶部会弹出「检测到上次使用的目录，点击恢复」，**点一下即可**

> 💡 建议在宣传屏上把该站点加入 Chrome 书签并设为启动页，配合「全屏」按钮（或按 `F` 键）使用。

### 推荐的全屏启动方式

给 Chrome 建一个快捷方式，目标填：

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --app=https://keyzhao0118.github.io/photowall/
```

`--kiosk` 会以无边框全屏运行，适合长期挂在大屏上。

## 🛠️ 技术实现

纯前端，零后端，零依赖。

| 模块 | 方案 |
|------|------|
| 初始锚点 | 轴向六边形坐标 `(q,r)` + 环形螺旋枚举，叠加抖动后用**互斥松弛**迭代 64 轮，得到有机散布 |
| 水流场 | 多重正弦叠加的平滑时空向量场，每张照片带独立相位偏移 |
| 牵引绳 | 超出松弛半径才回拉（`FREE_RADIUS=24px`），半径内完全自由 |
| 邻域加速 | 均匀空间哈希网格，只与 3×3 邻格内的照片计算互斥 |
| 防重叠 | **PBD 位置约束求解** ×2 轮：直接修正位置 + 抹掉法线方向靠近速度 |
| 波纹 | 扩散圆环扫过时施加径向冲力，随半径衰减 |
| 姿态 | 每张独立的自转摇摆（振幅/速度/相位各异）+ 受扰自旋衰减 |
| 渲染 | Canvas 2D，每张预渲染成圆形精灵图缓存，每帧仅一次带旋转的 `drawImage` |
| 目录读写 | File System Access API（`showDirectoryPicker`） |
| 句柄持久化 | IndexedDB 存储 `FileSystemDirectoryHandle` |
| 点赞存储 | 目录内 `photowall-likes.json`，降级到 `localStorage` |

### 物理仿真验证

用 Node + stub DOM 真实加载 `index.html` 并驱动物理引擎跑数千帧，实测结果：

| 指标 | 数值 |
|------|------|
| 平均游离锚点距离 | 40–46 px（证明不是刚性网格） |
| 静置自流速度 | 0.27–0.40 px/帧（持续微动，不会停） |
| 波纹峰值速度 | 6.66 px/帧 = 静置的 **22 倍** |
| 波纹最大撕开距离 | 517 px |
| 回归时间 | 900 帧内回到稳定态 |
| **最小照片间距** | **118.7 px > 圆直径 112 px（永不重叠）** |
| 物理耗时 | 30 张 0.15ms/帧；400 张 2.05ms/帧（占 60fps 预算 12%） |

## ❓ 常见问题

**Q：浏览器提示不支持文件系统访问 API？**
A：请用 Chrome 88+ 或 Edge 88+。Firefox / Safari 目前不支持该 API，此时页面会以内置演示照片运行。

**Q：为什么每次打开都要重新授权？**
A：这是浏览器的安全机制。本应用已做到最小化 —— 权限有效时全自动，失效时只需点一次「点击恢复」。

**Q：Google 字体加载不出来？**
A：站酷快乐体走 Google Fonts，若网络受限会自动回退到系统自带的圆润字体「幼圆」，观感接近。

**Q：照片很多会不会卡？**
A：不会。照片被预渲染成精灵图缓存，每帧只做一次 `drawImage`；屏幕外的照片直接跳过绘制。实测 150 张照片仍可稳定 60fps。
